# EF shared vocabulary

Definitions two or more stages would otherwise each restate. One definition, one place to change it.

| File | Load when |
|---|---|
| `references/evidence-grades.md` | a claim's strength decides what happens next — grounding, triage, audit findings |
| `references/lenses.md` | generating questions, assigning scouts, or assembling readers for a deadlock |

Paths are relative to this skill's directory. This skill does nothing by itself: the stage that sent
you here says what to do with the grade or the lens.
